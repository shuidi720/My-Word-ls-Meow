# 言出化喵 · 自动喵语化

一个基于 Android 无障碍服务（Accessibility Service）的**完全本地**文本自动变换工具：在任意 App 的输入框打字时，按你预设的规则实时完成子串替换、整句替换、句尾附加（随机喵尾）、标点触发与粘贴分句附加，把普通语句自动转成"喵语"风格。

全程离线运行，不申请网络权限，不上传任何数据。

---

## 功能特性

- **子串替换 / 整句替换**：两级规则，支持一条规则多个替换结果随机轮询；替换结果与已有后缀自动去重，不会叠出"喵喵"
- **句尾附加**：多后缀随机附加，已有后缀自动识别并保护，避免重复堆叠
- **标点触发 / 句号消费**：打句号、感叹号等句末标点时附加后缀；长文本粘贴时按分句附加，正常打字不触发分句，避免输入框反复刷新
- **语气符号后移**：`…` `～` 等延续语气符号自动保留在后缀之前，其余触发标点移到后缀之后
- **多套预设**：内置猫娘等预设，规则可自由编辑、导入、导出（JSON）
- **按应用启停 + 全局总开关**：可对单个 App 启用/停用；下拉通知栏磁贴一键开关触发，长按磁贴可快速切换功能开关、悬浮窗、标点触发、句号消费、分句触发
- **悬浮窗备用入口**：当部分 App 拦截无障碍写入时，可在悬浮窗内打字、实时变语后一键复制；收起悬浮窗期间不再弹权限引导
- **Shizuku 保活（可选）**：连接 Shizuku 后一键加入系统后台白名单 / Doze 白名单 / 待机桶，降低服务被国产 ROM 杀死的概率
- **日志页**：实时记录触发情况，连续重复日志自动合并并标注次数与时间范围

## 使用

1. 安装后打开 App，按引导开启**无障碍服务**（本应用的服务项）。
2. 在「规则」页选择预设（如猫娘），按需增删子串 / 整句 / 句尾附加规则。
3. 在「设置」页开启功能开关；建议把本应用加入系统自启动 / 后台白名单，并在最近任务列表下滑加锁，避免一键清理后无障碍掉线。
4. 打开任意聊天 App 正常打字即可看到效果。

> ⚠️ 无障碍权限可读取当前界面输入框内容。本应用完全离线、无任何网络代码，但请只从你信任的来源获取安装包，防止被二次打包注入恶意代码。

## 技术栈

Kotlin · AndroidX · Material Components · Room（本地规则数据库）· Shizuku API（可选保活）

## 构建

使用 Android Studio Hedgehog 及以上版本打开本项目，或命令行：

```bash
./gradlew assembleRelease
```

### 签名

仓库**不包含**任何签名文件。release 包默认回退到 debug 签名，clone 下来即可直接编译出包。

若要发布自己的正式签名，在项目根目录创建 `local.properties`（已在 `.gitignore` 中，不会提交）：

```properties
keystore.file=signing/your.keystore
keystore.password=你的仓库密码
keystore.alias=你的别名
keystore.aliasPassword=你的别名密码
```
